わんコメ用「OneSDK Probe」v0.1.0

【目的】
TwitCasting匿名コメントをOneSDKで受信したときの加工前データを
調査するための一時的な観測テンプレートです。
「初コメBIG」本体ではなく、初コメ判定や匿名番号判定は行いません。

【追加方法】
このREADME.txtが入っている one-sdk-probe フォルダを包んだZIPを、
わんコメの「テンプレート」画面へドラッグ＆ドロップしてください。
追加後に「OneSDK Probe」を開き、調査対象のコメントを投稿します。

【確認方法】
画面上部に最新コメントの主要フィールド、下部にRAW JSONが表示されます。
DevToolsのConsoleには各コメントのサマリーとRAWスナップショットが出ます。
window.__oneSDKProbeLog で、保存中の最大100件を確認できます。

Copy Logsは全ログをJSONでクリップボードへコピーします。
コピーできない環境では、同じJSONがConsoleへ出力されます。
Clear Logsはメモリ上のログと画面表示をリセットします。

【個人情報】
ログにはユーザーID、表示名、コメント本文などが含まれる可能性があります。
実ログを公開リポジトリへコミットしたり、不特定多数へ共有したりしないで
ください。このテンプレートは外部送信や永続保存を行いません。

【未確認】
このProbeのわんコメ実機インストール、実際のTwitCasting通常コメント、
匿名コメントの受信は未確認です。匿名番号の保存フィールドについても、
実データを取得するまでは結論を出していません。
